# 📈 Stock Price Prediction & Backtesting

## 📌 Overview
This project focuses on predicting stock prices and building a simple quantitative trading strategy using machine learning and technical indicators.

## 📊 Data
- Source: Historical stock data (VNM)
- Features: Price, Volume, Technical Indicators (EMA, RSI, Bollinger Bands)

## ⚙️ Methodology
- Data Cleaning & Preprocessing  
- Feature Engineering  
- Train/Test Split  
- Model: Linear Regression  
- Evaluation: RMSE ,MSE


## 🛠️ Technologies
- Python (Pandas, NumPy, Scikit-learn, Matplotlib)

## 📉 Results
MSE: 2.463063983644799
RMSE: 1.5694151724909502
